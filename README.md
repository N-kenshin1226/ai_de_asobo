# AIで遊ぼう

Google AI Studio（無料）の長いコンテキストを使って、AIをゲームマスターにして遊ぶためのプロンプト集。

## ゲーム一覧

| ゲーム | ジャンル | 元ネタの雰囲気 |
|---|---|---|
| [一族百年記](games/ichizoku_hyakunenki.md) | 家系図育成 | 俺の屍を越えてゆけ |
| [鐘の下で](games/kane_no_shita.md) | 育成型恋愛シミュレーション | ときめきメモリアル |

## AI Studio の設定（最初に1回だけ）

1. https://aistudio.google.com を開いて Google アカウントでログイン
2. **Create new prompt**（チャット）を開く
3. 右側の設定
   - モデル：Pro 系の最新モデル（物語の質が段違い）
   - Temperature：`1.0` 前後（低いと展開が単調になる）
   - **Code execution をON（必須）**：数値の計算はプロンプトに入っているPythonのエンジンが行うため
4. **System instructions** に各ゲームのプロンプトを貼る
5. 「はじめる」と送信

## しくみ

- 能力・好感度・遺伝などの数値は、すべてPythonのエンジンが計算し、毎ターン状態(STATE)として出力する
- Geminiは物語と会話を書くことと、プレイヤーの入力をエンジンへの指示に変えることだけを担当する
- そのため長く遊んでも数値がずれず、隠しパラメータも消えない

## 長く遊ぶコツ

- 毎ターン、エンジンと状態がチャットに積み上がるので、区切りのいいところで「セーブ」→ 新しいチャットに同じシステムプロンプトとセーブデータを貼って再開する
  - 鐘の下で：1学期ごと
  - 一族百年記：5年(20ターン)ごと

## Claude の使いどころ

- 「新しい神を5柱考えて」「隠しキャラを追加して」など、プロンプトの改造
- 「難しすぎる」「ヌルすぎる」というバランス調整
- セーブデータを貼って、作戦会議や答え合わせ
